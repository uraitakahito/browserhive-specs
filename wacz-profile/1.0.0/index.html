This specification profiles [[WACZ]]. It constrains how a WACZ package is written and defines the additional members BrowserHive records inside it, so that a reader holding only the archive can tell what the capture did and did not obtain.

This is a working draft. It has no standing beyond the BrowserHive project and is not endorsed by the publishers of [[WACZ]].

Scope

A file conforming to this profile is a conforming WACZ package. This document adds requirements; it removes none.
